# 하나되어 즐기삼

한 사이트의 커버에서 주관자용 또는 활동자용을 선택합니다. 각 폼은 한 페이지에서 작성하며, 노션 저장이 성공하면 엔딩을 표시합니다.

## VS Code·Claude Code에서 수정

| 파일 | 수정할 내용 |
| --- | --- |
| `public/index.html` | 공통 커버·푸터와 역할 선택 |
| `public/forms/organizer.html` | 주관자 폼과 완료 화면 |
| `public/forms/participant.html` | 활동자 폼, 체크리스트와 완료 화면 |
| `public/styles.css` | 색상, 여백, 모바일 레이아웃 |
| `public/assets/favicon.svg` | 브라우저 탭의 잎사귀 아이콘 |
| `public/app.js` | 화면 전환과 제출 상태 |
| `public/date-picker.js` | 활동일 입력칸과 달력 동작 |
| `netlify/functions/submit.mjs` | 타임 조회와 노션 속성 매핑 |
| `netlify/lib/daily-analysis.mjs` | 활동자 링크와 일별 AI 분석 갱신 |
| `netlify/lib/activity-journal.mjs` | 날짜별 활동 일지의 보고용 텍스트 작성 |

체크리스트 문구를 바꿀 때는 활동자 폼과 `submit.mjs`의 노션 상세 문구를 함께 수정합니다. 문항 수를 바꿀 때는 폼의 점수 그룹 이름(`score1` 등), `SCORE_PROPERTIES`, 노션 숫자 속성을 함께 맞춥니다. 타임 선택지를 바꿀 때는 해당 폼과 `submit.mjs`의 검증 규칙을 함께 수정합니다.

## Netlify와 노션 설정

저장소를 Netlify에 연결하고 Base directory는 저장소 루트로 둡니다. `netlify.toml`에서 공개 폴더 `public`과 함수 폴더를 지정하므로 빌드 명령은 필요 없습니다. 첫 화면이 필요한 폼 HTML을 불러오며, 커버·두 폼·완료 화면 모두 같은 사이트 루트 주소를 사용합니다. 로컬에서도 폼을 불러올 수 있도록 저장소 루트에서 `npx netlify-cli dev`를 실행하고 터미널에 표시된 `http://localhost:8888/` 같은 루트 주소를 엽니다.

노션에 내부 연동을 만들고 이 사이트가 사용하는 DB에 접근을 부여합니다. Netlify 환경 변수는 Functions에서 사용할 수 있도록 지정합니다. 로컬에서는 같은 이름을 `.env`에 설정합니다.

| 환경 변수 | 값 |
| --- | --- |
| `NOTION_TOKEN` | 노션 내부 연동 토큰 |
| `NOTION_SESSIONS_DATA_SOURCE_ID` | 두 폼이 공유하는 `타임별 사후 보고` 데이터 소스 ID |
| `NOTION_PARTICIPANTS_DATA_SOURCE_ID` | `사후 작성 내역`의 활동자 응답 데이터 소스 ID |
| `NOTION_DAILY_ANALYSIS_PAGE_ID` | `일별 AI 분석` 상위 페이지 ID. 날짜별 집계와 일별 활동 일지에 사용 |
| `DAILY_AI_ENABLED` | 기본 비활성화. `true`로 설정하면 AI 해석 사용 |

노션 연동에 두 DB를 연결하고 읽기·수정·추가 권한을 설정합니다. Netlify Blobs는 같은 타임을 동시에 생성하는 것을 막는 데 사용합니다. 저장소에 `package.json`과 `package-lock.json`을 포함하면 Netlify가 배포 때 의존성을 설치합니다.

일별 집계를 쓰려면 같은 내부 연동에 `일별 AI 분석` 페이지도 연결합니다. 제출 후 예약 함수가 2분 간격으로 대기 중인 날짜를 처리합니다. 활동자 응답은 같은 타임의 주관자 본문에 링크로 반영되고, 일별 집계와 키워드 분류는 같은 날짜의 페이지에서 갱신됩니다. AI 해석을 켠 경우에는 Netlify AI Gateway나 운영 환경의 `ANTHROPIC_API_KEY`를 사용하고, AI에 집계 숫자와 주제 분류를 전달합니다. [Netlify AI Gateway](https://docs.netlify.com/build/ai-gateway/overview/)

노션 계정이나 워크스페이스를 바꿀 때는 새 워크스페이스에서 내부 연동을 만들고 DB에 연결한 뒤, 이 Netlify 사이트의 환경 변수를 바꾸고 다시 배포하세요. 노션 속성 이름과 유형이 같으면 코드 수정 없이 옮길 수 있습니다. 토큰은 저장소에 올리지 마세요.

## 타임별 사후 보고 DB

| 속성 | 유형 |
| --- | --- |
| `타임명` | 제목 |
| `타임 키` | 텍스트 |
| `주관자 이름` | 텍스트 |
| `주관 시간` | 텍스트 |
| `활동 장소` | 텍스트. 주관자가 선택한 장소 |
| `실제 참여 인원` | 숫자 |
| `전체 찾기 건수` | 숫자 |
| `변경·지연·누락 사유` | 이전 주관자 양식의 텍스트 기록 |
| `특이사항` | 텍스트 |
| `물약 포지션` | 텍스트. 담당자 성명 |
| `묵상 말씀 준비`, `인원 목표 확인`, `분위기 살피며 독려`, `2인 1조 짝짓기` | 텍스트. `예` 또는 `아니오` |
| `주관자 제출 완료` | 체크박스 |

타임 키는 `2026-11-06 | 1타임` 또는 `2026-11-06 | 그 외`처럼 활동일과 선택한 타임으로 구성됩니다. 해당 키가 없으면 첫 제출이 같은 이름의 타임 페이지를 생성합니다. 같은 날짜에 `그 외`를 선택한 주관자와 활동자의 보고는 한 타임 페이지에 모입니다. 주관자가 같은 타임에 다시 제출하면 보고가 갱신됩니다. 입력한 주관 타임과 시작·종료 시간은 타임 페이지의 `상세내역 → 활동 정보`에 표시됩니다.

## 참여자 응답 DB

| 속성 | 유형 |
| --- | --- |
| `활동자 이름` | 제목. 활동자 성명으로 채움 |
| `타임` | `타임별 사후 보고`를 가리키는 관계형. 타임 DB에도 표시를 켜면 연결된 응답을 볼 수 있음 |
| `활동 시간` | 텍스트. 실제 활동 구간별로 한 줄 |
| `활동 장소` | 텍스트. 활동자가 선택한 장소 |
| `긍정적인 마음`, `함께 활동`, `옆사람 독려`, `목표건 도달` | 숫자. 새 체크리스트 1~3점 |
| `활동 이해`, `안내 준수`, `활동 범위 확인`, `찾기 기록` | 숫자. 이전 체크리스트 1~5점 기록 |
| `본인 찾기 건수` | 숫자 |
| `비고` | 텍스트. 기존 `건의사항` 속성의 이름을 바꾸면 이전 입력값도 같은 열에 표시 |

활동자가 먼저 제출하면 타임 페이지와 활동자 응답이 생성됩니다. 주관자가 이후에 제출하면 같은 페이지에 주관자 보고가 채워집니다.

활동 타임과 실제 활동 시간은 활동자 응답 페이지의 `상세내역 → 활동 정보`에 표시됩니다. 여러 구간은 입력 순서대로 기록됩니다. `활동 결과`에는 체크리스트 질문, 답과 점수가 표시됩니다. 일별 집계는 새 3점 척도와 이전 5점 척도를 각각 계산합니다.

두 폼에서 선택한 장소는 각각의 노션 상세에도 저장됩니다. 연동이 데이터 소스의 스키마를 수정할 수 있으면 장소와 시간 텍스트 속성을 첫 제출 때 추가합니다. [Notion 데이터 소스 속성 API](https://developers.notion.com/reference/update-data-source-properties)

## 일별 활동 일지

노션의 `일별 AI 분석 → 일별 활동 일지`에서 날짜 페이지를 열고 코드 블록의 `복사`를 눌러 보고용 텍스트를 가져옵니다. 각 타임의 제목에 주관자가 입력한 시간과 장소를 표기합니다. 활동자 줄은 선택한 타임 아래에 `이름(시작-종료)` 형식으로 들어가며 여러 구간은 쉼표로 구분합니다. `그 외`에 제출한 기록은 `그외 활동`에 `이름/시간/장소` 형식으로 들어갑니다.

제출이 접수되면 예약 함수가 같은 날짜의 일지를 갱신합니다. 이전 기록에 입력값이 없으면 `시간 미기록` 또는 `장소 미기록`으로 표시합니다.

## 노션 활동 내역 화면

1. `참여자 응답` DB의 `타임` 관계형을 양방향으로 설정하고, `타임별 사후 보고` 쪽 관계형 이름을 `활동자 응답`으로 지정합니다. 한 타임에 여러 응답이 표시되도록 이쪽 관계형의 페이지 수 제한은 해제합니다.
2. `타임별 사후 보고` DB를 전체 페이지로 열고 `··· → 모양 및 레이아웃 → 레이아웃 사용자 지정`으로 들어갑니다. 속성 그룹에 `주관자 보고`와 `활동자 응답` 섹션을 추가합니다. 주관자 이름, 인원, 건수, 사유, 특이사항, 제출 완료 여부는 첫 섹션으로 옮기고, `활동자 응답` 관계형은 두 번째 섹션에 둡니다. `모든 페이지에 적용`을 선택합니다.
3. 한 타임 페이지에서 `활동자 응답` 관계형 필드의 `···`를 열고 표시할 속성을 선택합니다. 예를 들어 `본인 찾기 건수`와 `비고`를 표시하면 활동자 이름 옆에서 바로 볼 수 있습니다.

배포 후에는 아직 없는 날짜와 타임으로 활동자와 주관자 테스트를 한 건씩 보내고, 타임 페이지가 하나만 생기며 그 안에 두 결과가 보이는지 확인합니다.
